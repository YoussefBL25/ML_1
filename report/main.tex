\section{Data and preprocessing}\label{sec:data}
\pending{Person 1, data description: training and test sizes, class
balance, missing values, feature types. Numbers from the shared EDA:
328,135 training and 109,379 test respondents, 321 features, 8.8\% positive,
44.8\% of all values missing, 147 features missing for more than half of the
respondents, mostly from optional state modules. Optional: EDA figure.}

The features are coded survey answers. Steps 1 to 3 convert them into
meaningful values, following the BRFSS 2015 codebook~\cite{brfss15}, which
we checked for every feature; they do not use the labels.
\begin{enumerate}
\item \emph{Special codes.} The codes for ``don't know'' and ``refused'',
  such as 7 and 9, become missing values, and the codes for ``none'', 88,
  888 or 555, become 0. For example, $62\%$ of the respondents report 88 =
  ``no days'' of poor physical health, otherwise read as 88 days.
\item \emph{Column removal.} We remove $64$ features: $32$ describe the
  survey, such as identifiers and weights, $29$ are raw answers that also
  exist in a cleaned version, such as WEIGHT2 replaced by WTKG3, and $3$ are
  nominal. Two of these give the type of physical activity, with 77
  categories, already summarized by the calculated energy cost, intensity
  and weekly minutes of activity; the third is $99.9\%$ missing.
\item \emph{Nominal features.} Seven features use numbers as category
  labels, such as state and marital status, and are one-hot encoded.
\item \emph{Imputation and scaling.} \pending{Person 1: median imputation,
  standardization, bias column; all statistics learned on training rows
  only.}
\end{enumerate}

\textit{Features of the final model.} Each feature with missing values gets
an indicator equal to 1 when the value is missing. Missingness is
informative, because many questions are only asked after a given answer:
the age at diabetes diagnosis is missing for respondents without diabetes.
All 86 features with 3 to 10 observed values are also one-hot encoded, so
that each level of, for instance, general health has its own effect.

\subsection{Evaluation protocol}\label{sec:protocol}
We use nested cross-validation, so that the data used to choose a model is
never used to evaluate it. All methods share five stratified folds, with
seed 0.
\begin{enumerate}
\item \emph{Outer loop.} Each fold is the test fold once; the other four
  form the training set.
\item \emph{Inner loop.} Three folds of the training set select the
  hyperparameters and the threshold $t\in\{0.05,0.06,\dots,0.95\}$ with the
  best F1.
\item \emph{Evaluation.} The selected model is retrained on the training
  set and scored on the test fold.
\end{enumerate}
We report the mean and standard deviation of F1 over the test folds. A
per-fold difference $\Delta$ between two configurations is considered real
only if it has the same sign in all five folds. All statistics are learned
on training data, and the submitted model is selected by the inner loop on
the full training set.

\subsection{Logistic models}\label{sec:methods}
With labels $y\in\{0,1\}$, logistic regression minimizes the mean negative
log-likelihood
$L(w)=\frac1N\sum_i\bigl[\log(1+e^{x_i^\top w})-y_i x_i^\top w\bigr]$,
computed with \texttt{logaddexp} for numerical stability; regularized
logistic regression adds $\lambda\|w\|^2$. Both use full-batch gradient
descent from $w=0$ for 300 iterations, after which the loss changes by less
than $0.06\%$. We search $\gamma\in\{0.01,0.03,0.1,0.3,1\}$, around the
convergence bound $\gamma<0.57$ given by the largest eigenvalue of
$X^\top X/N$, and $\lambda\in\{10^{-6},\dots,10^{-1}\}$.

\subsection{Class imbalance}\label{sec:imbalance}
Only $8.8\%$ of the samples are positive. Besides threshold tuning, we
weight the positive samples by $\omega\in\{1,\sqrt r,r\}$, where
$r=n_-/n_+\approx10.3$. For a well-specified model, this multiplies the
predicted odds by $\omega$, so a threshold $t$ becomes $t'$ with
$t'/(1-t')=\omega\,t/(1-t)$, and weighting should add little to threshold
tuning.

\subsection{Final model}\label{sec:final}
A linear model cannot represent the joint effect of two features, for
instance that smoking matters more for older respondents. The final model,
regularized logistic regression with $\gamma=0.3$ and $\lambda=10^{-4}$, is
therefore fitted twice: a first fit ranks the features by $|w_j|$, then the
780 products of the 40 top features are standardized and added, and the
model is refit. The number 40 was chosen among $\{20,30,\dots,80\}$ by
3-fold cross-validation.

\textit{Logistic models.} Plain and regularized logistic regression are
tied, with $\Delta=0.0003\pm0.0014$. Regularization does not help because
the model does not overfit: the training and validation losses are $0.219$
and $0.221$. Accuracy is not informative, since always predicting ``no
disease'' gives $0.912$.

\textit{Features.} The codebook rules give the largest gain
(Table~\ref{tab:ablation}), entirely through precision, which rises from
$0.338$ to $0.359$. The indicators and one-hot features add $0.006$ in
every fold. The interactions add $0.003$, but in four folds out of five, so
this gain is likely but not certain. On the AIcrowd test set, the final
model reaches F1 $=0.450$ and accuracy $0.878$. Squared, binned or
log-transformed features, more interactions, a larger penalty and model
averaging changed F1 by less than $0.001$.

\textit{Class weighting.} It changes F1 by at most $0.0013$ but moves the
threshold from $0.21$ to $0.48$ and $0.75$, close to the values $0.46$ and
$0.73$ predicted in Section~\ref{sec:imbalance}: threshold tuning already
handles the imbalance.
