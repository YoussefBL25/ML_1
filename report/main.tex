\section{Data and preprocessing}\label{sec:data}
The training set contains $328{,}135$ respondents and $321$ features (test:
$109{,}379$); only $8.8\%$ are positive. Overall $44.8\%$ of the values are
missing, and $147$ features are missing for more than half of the
respondents, mostly questions from optional state modules.

The features are survey answers with special codes. Following the BRFSS 2015
codebook~\cite{brfss15}, ``don't know''/``refused'' codes (7/9, 77/99,
777/999 and column-specific variants) are treated as missing, and ``none''
codes (88, 888, 555) are set to 0; e.g.\ for PHYSHLTH (days of poor physical
health), $62\%$ of answers are 88 = ``no days''. We remove $64$ columns:
identifiers, interview dates, survey weights, raw answers that the codebook
also provides as cleaned calculated variables (e.g.\ WEIGHT2 vs.\ WTKG3), and
three nominal codes with many levels (e.g.\ type of physical activity). Seven nominal variables (state, marital
status, employment, race, home ownership, blood pressure and diabetes status)
are one-hot encoded. Remaining missing values are imputed with the training
median, all features are standardized and a bias column is added. All
statistics (medians, means, standard deviations, category levels) are
learned on training rows only (Section~\ref{sec:protocol}).

\subsection{Logistic models}\label{sec:methods}
Labels are mapped from $\{-1,1\}$ to $y\in\{0,1\}$. Logistic regression
minimizes the mean negative log-likelihood
$L(w)=\frac1N\sum_i \log(1+e^{x_i^\top w})-y_i x_i^\top w$, evaluated with
\texttt{logaddexp} for numerical stability; the regularized variant adds
$\lambda\|w\|^2$ (bias included). Both use full-batch gradient descent from
$w=0$.

\textit{Hyperparameter tuning} proceeds in three steps. (i)~\emph{Ranges
from theory.} The logistic Hessian is bounded by $X^\top X/(4N)$, so gradient
descent is guaranteed to converge for $\gamma<8/\lambda_{\max}(X^\top X/N)$;
power iteration gives $\lambda_{\max}\approx14.0$, i.e.\ $\gamma<0.57$, and we
take $\gamma\in\{0.1,0.25,0.5\}$. At $\gamma=0.5$ the training loss changes by
$0.06\%$ between 300 and 600 iterations, so we fix 300 iterations. Training
and validation losses are nearly equal ($0.219$ vs.\ $0.221$): the model
underfits, so $\lambda$ only needs one value per decade, from no visible
effect to a clear penalty, $\lambda\in\{10^{-4},10^{-3},10^{-2}\}$.
(ii)~\emph{Selection.} All $3+9$ combinations are scored by inner CV in every
outer fold (Section~\ref{sec:protocol}), and the combination and threshold
with the highest inner-CV F1 are kept. Applied to the full training set
(Table~\ref{tab:grid}), this rule gives the final models: $\gamma=0.5$ for
logistic regression and $\gamma=0.5$, $\lambda=10^{-3}$ for the regularized
variant, both with threshold $0.20$. $\gamma=0.1$ has not converged
($-0.004$), $\lambda=10^{-2}$ over-regularizes ($-0.004$), and the remaining
combinations lie within $0.0007$ of each other, well below the inner-fold
standard deviation ($\approx0.003$): they are statistically tied, and the
outer folds select only among them. (iii)~\emph{Resolution check.} A wider
sweep on a development split inside the first outer training fold
(Fig.~\ref{fig:sweep}) shows that F1 is flat for $\gamma\in[0.5,1]$ and
$\lambda\le10^{-3}$, and drops outside, so a finer grid cannot gain more than
$0.0001$.

\subsection{Evaluation protocol}\label{sec:protocol}
All six methods use the same nested stratified cross-validation (seed 0):
5 outer folds estimate performance; inside each outer training part, 3 inner
folds select the hyperparameters and the decision threshold
($0.05,0.06,\dots,0.95$) maximizing F1 on out-of-fold predictions. Outer
folds are used only for scoring, and every preprocessing statistic is
learned on training rows only. We report the mean $\pm$ standard deviation
of F1 over outer folds, and treat differences smaller than one standard
deviation as ties.

\subsection{Class imbalance}
Threshold tuning already compensates part of the imbalance; as a
modification of logistic regression we additionally weight the loss of
positive samples by $\omega\in\{1,\sqrt r, r\}$, with $r=n_-/n_+\approx10.3$
computed on each training part and weights normalized to mean one.
$\omega=1$ recovers regularized logistic regression exactly.

Logistic and regularized logistic regression tie ($0.431\pm0.005$), as
expected from the flat tuning grid (Table~\ref{tab:grid}): the selected
penalty is always small ($\lambda\le10^{-3}$) and $\gamma=0.5$ is selected in
9 of 10 outer folds. Accuracy is not informative here:
predicting ``no disease'' for everyone already reaches $0.912$, above every
model in Table~\ref{tab:methods}. At the F1-optimal threshold ($\approx0.2$)
the models trade accuracy for recall, detecting $54\%$ of positive cases with
a precision of $36\%$.

The largest effect in the ablation (Table~\ref{tab:ablation}) comes from
preprocessing: applying the codebook rules raises F1 by $0.016$ (about three
fold standard deviations) for both logistic models, almost entirely through
precision ($0.339\to0.359$ at equal recall), since, e.g., ``88 = no days of
poor health'' no longer reads as 88 days. Class weighting, in contrast, has
no effect: as $\omega$ grows the selected threshold rises from $0.22$ to
$0.75$ while F1 stays within $0.001$. Weighting mostly shifts the predicted
probabilities, which threshold tuning already compensates, so the imbalance
is handled by the threshold alone. Since the model underfits, further gains
should come from richer features rather than from regularization or
reweighting.
